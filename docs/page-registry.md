## Notes

- **Article/adventure names, contributor names, trip prices/details, and FAQ copy are all original** — invented for this project rather than copied from the reference, per the user's explicit "use mocks for everything" instruction. The "Reference URL" column above records which *reference page's structure* a mock page's template is based on, not a content source.
- **Images**: all 42 images in `/images/` are generated placeholder SVGs (abstract gradient/line illustrations), not fetched from the reference. DA's own image pipeline re-hosts each one as responsive `<picture>` variants (webp + svg, multiple widths) — this happens automatically for any absolute image URL referenced in an authored document.
- **Scope reduction**: the reference's 7-country/language selector and `/us/en/...`-style locale routing were not implemented — see `docs/component-registry.md`'s note on `.nav-region`.
- **Bugs found and fixed** (see `docs/component-registry.md`'s DA authoring constraint note for the full explanation of the root cause): header/footer CSS wasn't loading at all (JS-only import bug); `hero`'s single-image variant never rendered (missing `data-active`); the mobile nav toggle's expand/collapse logic was inverted; a hero CSS rule collapsed every single-image hero to zero height once pictures had to be div-wrapped for DA; `breadcrumbs`/`meta-list`/`filters`/`byline` all lost their styling because they were authored as native lists/plain text rather than div-row blocks (rebuilt as real blocks); footer social-icon `aria-label`s were being stripped (now set client-side); plus a color-contrast failure, two touch-target-size failures, a missing `<h2>` heading-order gap, and a generic "Read more" link failing the SEO link-text audit.
- **Lighthouse CLS noise**: one measurement run showed a spurious CLS regression (score 0.21) on two pages when testing against the live CDN over a real network; re-running the exact same audit immediately after returned a perfect score (0). Treated as lab-data network variance (a documented Lighthouse limitation for real, non-localhost targets), not a real defect — confirmed by a third, fully clean re-run across all seven sampled pages.
